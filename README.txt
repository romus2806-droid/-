Кристальный мэтч — установка
1. Загрузи все файлы из этой папки на любой хостинг с https (GitHub Pages, Netlify, Cloudflare Pages).
2. Открой адрес на телефоне: в Chrome нажми «Установить приложение», в Safari — «Поделиться» > «На экран Домой».
3. Чтобы выпустить обновление, измени версию V в sw.js (например gems-v2), иначе у игроков останется старая копия.
